# Integration

Place future external adapters in `App\Integration`. Before wiring a UniversalMcpGateway adapter, verify its [charter](https://github.com/Koshai/UniversalMcpGateway/blob/master/docs/PROJECT_CHARTER.md) and [checklist](https://github.com/Koshai/UniversalMcpGateway/blob/master/docs/DEVELOPMENT_CHECKLIST.md). Keep capability authorization and business operations inside HRMS.
